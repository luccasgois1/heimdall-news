# Câmara e Senado em cada governo

Como cada casa votou durante cada mandato presidencial desde 2003, a partir das votações nominais do Plenário. Polos de cada mandato: bancada do partido do governo × bancada do principal partido de oposição. Mandatos encerrados ficam congelados; o atual é atualizado toda semana. A metodologia está em [Posicionamento dos partidos em cada governo](../estudos/espectro.md).
